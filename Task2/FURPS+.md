| Код | Требования                                                                                                 | Комментарий |
| --- | ---------------------------------------------------------------------------------------------------------- | ----------- |
| F   | Функциональные (Functionality)                                                                             |             |
| F1  | Сайт и интернет-банк отображают актуальные условия по депозитам и кредитам                                 |             |
| F2  | Клиент может подать заявку на депозит или кредит через сайт и интернет-банк                                |             |
| F3  | Заявки из интернет-банка подтверждаются СМС-кодом                                                          |             |
| F4  | Менеджер кол-центра может просматривать заявки с сайта и работать с клиентом                               |             |
| F5  | Сотрудники бэк-офиса могут работать со ставками и обрабатывать заявки                                      |             |
| F6  | Для кредитной заявки выполняется скоринг и при наличии необходимых данных выдаётся предварительное решение |             |
| F7  | Сотрудник отделения может создать новую или продолжить ранее созданную кредитную заявку                    |             |
| F8  | Клиент получает СМС о событиях по депозитной или кредитной заявке                                          |             |
|     |                                                                                                            |             |
| U   | Удобство использования (Usability)                                                                         |             |
| U1  | Интерфейсы сайта и интернет-банка должны быть максимально удобными для клиента                             |             |
| U2  | Интерфейсы должны соответствовать принятой в банке дизайн-системе                                          |             |
| U3  | Интерфейсы должны использовать привычные клиентам цвета и брендированные элементы банка                    |             |
|     |                                                                                                            |             |
| R   | Надёжность (Reliability)                                                                                   |             |
| R1  | Сервисы должны работать 24/7                                                                               |             |
| R2  | Доступность сервисов должна составлять не менее 99,9%                                                      |             |
| R3  | В случае сбоя основного ЦОД сервисы интернет-банка должны оставаться доступными                            |             |
|     |                                                                                                            |             |
| P   | Производительность (Performance)                                                                           |             |
| P1  | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды                           |             |
| P2  | Необходимо предусмотреть горизонтальное масштабирование                                                    |             |
| P2  | Необходимо предусмотреть равномерное распределение запросов между серверами                                |             |
| P3  | Онлайн-подача заявок не должна ставить под угрозу работоспособность АБС                                    |             |
| P4  | Заявки по предодобренным кредитным предложениям должны обрабатываться в течение того же рабочего дня       |             |
|     |                                                                                                            |             |
| S   | Поддерживаемость (Supportability)                                                                          |             |
| S1  | Должна быть разработана техническая документация                                                           |             |
| S2  | Новые решения должны по возможности использовать существующую экспертизу банка                             |             |
|     |                                                                                                            |             |
| +R  | + Ограничения (Restrictions)                                                                               |             |
| +R1 | Передача чувствительных данных должна выполняться по защищённым зашифрованным каналам                      |             |
| +R2 | Следует максимально использовать существующий технологический стек и компетенции банка                     |             |
| +R3 | В новом процессе следует избегать прямой работы интернет-банка с API АБС                                   |             |
| +R4 | При необходимости брокера сообщений предпочтительно использовать Kafka                                     |             |
| +R5 | Допускается рассмотреть переход интернет-банка к микросервисной архитектуре                                |             |
| +R6 | Следует избежать доработки ядра интернет-банка со стороны подрядчика                                       |             |
|     |                                                                                                            |             |
